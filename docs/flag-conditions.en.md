## How to read this catalogue

- `flagSetId` identifies a definition. Its eight `rawConditionSlots` are a separate numeric domain; no bit-index encoding is assumed.
- A label such as `townGradeUpData / Item Shop` means that record references the set. It does not mean setting one value recruits an NPC, grants a building, or satisfies all other prerequisites.
- `gameplayMeaning` and `conditionLogic` stay null until validated. No all-4096 set is called always-on, and no missing reference is silently treated as empty.
- Area labels use the same source-group index and area number. Group indices are not mapped to region numbers; navigation targets are not treated as owning regions.
- `unidentified` means no descriptive name was found in the analyzed references, not that a definition is unused by the game.
- Original reference slots and their table/group/row/field locations are in the JSON. Repeated raw values have a reverse index there.
