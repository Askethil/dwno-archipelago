# Catalogue des compétences du dresseur

71 compétences observées en jeu le 2 novembre 2026, réparties dans 4 catégories et 16 sous-groupes. Coût cumulé : **500 PC**, réparti sur deux séries après reset ; il ne représente pas le solde disponible en une seule session. Dernier solde observé : **17 PC**.

Les noms internes, coûts et bits proviennent des traces locales. Les catégories et sous-groupes français sont ceux annoncés par le joueur. Les libellés anglais ci-dessous sont publiés dans le [guide Twinfinite](https://twinfinite.net/guides/all-tamer-skills-in-digimon-world-next-order/) ; ils sont sourcés, mais restent à confirmer dans notre interface PC. Ce sont des libellés, pas des traductions inventées. Les noms individuels anglais ne sont pas encore renseignés ; seul le nom français de MOOD_UP est confirmé.

Le [manuel officiel anglais](https://d1vtv52f4vjbmu.cloudfront.net/manuals/dwno/PS4-DWNO_manual_GBQS_WEB.pdf) présente aussi les quatre catégories et les sous-groupes Basic. Référence historique PS4 ; ne pas supposer sans contrôle que toute la localisation est identique à la version PC actuelle.

## Utilisation et limites

- Index de bits et de mots basés sur zéro. Le bit global 64 est le bit 0 du deuxième mot UInt64. Un index de bit observé ne constitue pas encore un ID Archipelago.
- Apprentissage observé : SetLearningSkillFlag(skill, True), puis AddSkillPoint avec un montant négatif. Reset observé : AllResetLearningSkill, remboursements via AddSkillPoint, flags effacés. Le second reset est suivi de AddMoney(-10000).
- Le mod observe uniquement. Attribution forcée, retrait individuel, effets sur les partenaires, prérequis et persistance après rechargement ne sont pas validés.
- Pour confirmer les noms anglais sur PC : sauvegarder, passer la langue des textes en anglais dans les réglages disponibles du jeu/Steam, puis relever les libellés sans racheter les compétences. Aucun changement de langue effectué pendant cette collecte.
- Données réutilisables : [JSON](../data/tamer-skills.json). Détails chronologiques et soldes avant/après : [rapport des essais](observation-tamer.md). Les journaux bruts restent locaux et les fichiers du jeu ne sont pas publiés.
